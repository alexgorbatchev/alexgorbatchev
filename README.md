# Alex Gorbatchev

## Dotfiles

[dotfiles](https://github.com/alexgorbatchev/dotfiles) is a CLI for managing tools, dotfiles, and shell configuration across machines. Define tools declaratively, install them on first use, and make them available to both shells and GUI applications.

[Documentation](https://alexgorbatchev.github.io/dotfiles/)

## AI tools and libraries

- [agent-parser](https://github.com/alexgorbatchev/agent-parser) — Parse Claude Code, Pi, Codex, and OpenCode transcripts and databases into a shared event model.
- [agent-print-session-cli](https://github.com/alexgorbatchev/agent-print-session-cli) — Inspect, summarize, filter, and print Claude Code and Pi session transcripts.
- [agent-watcher](https://github.com/alexgorbatchev/agent-watcher) — Discover coding agent sessions and stream lifecycle and activity events with acknowledged checkpoints for restart replay.
- [agentation-cli](https://github.com/alexgorbatchev/agentation-cli) — CLI companion for the Agentation fork.
- [ai-registry](https://github.com/alexgorbatchev/ai-registry) — My canonical registry of reusable AI skills, commands, and profiles, with generated configuration for different coding agent harnesses.
- [tiktoken-cli](https://github.com/alexgorbatchev/tiktoken-cli) — Count tokens using OpenAI's tiktoken tokenizer.
- [ts-unused](https://github.com/alexgorbatchev/ts-unused) — Audit TypeScript projects for unused exports, files, and type properties, with output for AI cleanup workflows and VS Code integration.

## Music and DJ tools

- [djtools](https://github.com/alexgorbatchev/djtools) — Go library for manipulating and converting DJ libraries, including playlists, cue points, loops, and beat grids. Maintained fork of [nateranda/djtools](https://github.com/nateranda/djtools).
- [engine-cli](https://github.com/alexgorbatchev/engine-cli) — Manage playlists and tracks, audit and repair Engine DJ libraries, normalize artwork, and back up collections.
- [fetch-mix-cli](https://github.com/alexgorbatchev/fetch-mix-cli) — Discover DJ set tracklists, download their individual tracks, and create playlists in set order.
- [fetch-track-cli](https://github.com/alexgorbatchev/fetch-track-cli) — Find and download individual tracks, check audio quality, and embed metadata and cover art.
- [gochromaprint](https://github.com/alexgorbatchev/gochromaprint) — Pure Go port of [Chromaprint](https://acoustid.org/chromaprint), with a `fpcalc` CLI for generating acoustic fingerprints and a library for fingerprint comparison.
- [goshazam](https://github.com/alexgorbatchev/goshazam) — Pure Go port of the Python library [ShazamIO](https://github.com/dotX12/ShazamIO), with a CLI for song recognition and Shazam catalog queries.
- [shazam-cli](https://github.com/alexgorbatchev/shazam-cli) — Fetch, cache, list, and export your Shazam library from the command line.
- [tag-track-cli](https://github.com/alexgorbatchev/tag-track-cli) — Identify audio files and update metadata and square cover art without lossy audio re-encoding.

- [toon-cli](https://github.com/alexgorbatchev/toon-cli) — Convert JSON, JSONC, or NDJSON from standard input into TOON.
